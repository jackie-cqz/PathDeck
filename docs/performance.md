# M3 性能实测

日期：2026-10-30。测量入口为真实 AppKit 应用的 `--performance-test`，不是只测枚举函数，也没有用虚构数据代替文件。

## 环境与方法

- Mac 型号 `Mac16,12`，Apple Silicon arm64，24 GiB 内存。
- macOS 27.2 / 26B123；Apple Swift 6.4 (`swiftlang-6.4.0.34.1`)，Command Line Tools，Release 优化构建、本地 ad-hoc 签名。
- 临时目录在本地 APFS SSD。后台真实创建 1,000 和 10,000 个空文本文件；生成数据用时单独记录，不计入目录跳转耗时。
- 每个目录访问三次，每次先回到根夹具，再从调用导航开始计时，到读取提交、表格行数正确、布局及 `displayIfNeeded()` 完成为止。包含元数据和可见行绘制；不保证 GPU 已呈现在物理屏幕上。
- 文件刚创建且会重复读取，**系统缓存已热**。未使用 `purge`、重启、管理员权限或修改系统设置。
- 主线程以约 10 ms 间隔调度心跳，记录最大间隔；物理内存使用当前进程 `TASK_VM_INFO.phys_footprint`。
- 完成 50 次不等待的快速导航，再进行 10 次完成的目录切换/滚动，检查最终行数、监听和图标缓存。停止监听后计数必须为 0。

## 结果

最新运行的具体数据由 `build/validation/performance.json` 记录；以下表格随本轮最终运行更新。

| 项目 | 结果 | 规格目标/解释 |
| --- | --- | --- |
| 1,000 项三次显示耗时 | 106.0 / 99.8 / 97.7 ms，中位数 **99.8 ms** | 目标中位数 <500 ms，通过 |
| 10,000 项三次显示耗时 | 656.1 / 653.1 / 650.4 ms，中位数 **653.1 ms** | 目标中位数 <2,000 ms，通过 |
| 启动到夹具列表显示 | 179.9 ms | 从 app `main` 计时，只有少量项目；不是冷缓存启动 |
| 最大主线程心跳间隔 | 65.6 ms | 包含原生布局、排序和绘制，非帧率/交互延迟保证 |
| 导航/滚动前后物理内存 | 58.1 → 65.7 MiB | 有限次数采样，不等同长期泄漏结论 |
| 导航后的监听 / 停止后 | 32 / 0 | 监听上限 64，停止后 0 |
| 图标缓存 | 2 项 | 上限 128；按文件类型缓存，非每文件缩略图 |
| 50 次快速导航 | 通过 | 最后请求提交正确，无旧结果覆盖 |

每次访问均校验实际 1,000/10,000 行且状态 loaded。当前数据不覆盖大文件内容读取、复杂 package、网络/云盘延迟、冷图标服务或真实 TCC 弹窗。不能把小夹具启动耗时当成“大目录冷启动”指标。

本轮数据夹具生成耗时 490.5 ms，独立于上述导航时间。完整 JSON 和环境输出保留在本地验证目录。

## 实现与限制

目录 IO 使用有并发上限的后台队列；已取消的排队读取跳过执行。导航在创建请求前检查任务取消，避免快速连续操作中较晚被调度的旧任务夺取状态。完整元数据枚举后才提交列表，尚未实现分批首屏加载；测试数据通过目标，不代表超大目录也会同样快。

表格复用单元格，只为可见行创建视图；类型图标缓存有上限，滚动不逐文件加载缩略图。当前排序仍可能占用少量主线程时间，心跳结果用于暴露这一点。vnode 监听范围有上限，不会递归监听整个磁盘；未监听到的变化可通过激活窗口或 ⌘R 刷新恢复。

```bash
DEVELOPER_DIR=/Library/Developer/CommandLineTools bash scripts/performance.sh
```

需要图形登录会话，会创建/清理唯一临时夹具并退出。生成环境、构建和 JSON 报告均保存在 `build/validation/`。


## v0.2 补测

新增窗口/标签、预览/属性与外观后，Release 本机热缓存三次访问中位数：1,000 项 **99.5 ms**、10,000 项 **646.2 ms**；10,000 项名称过滤 **47.9 ms**。50 次快速导航最终状态正确。当前页监听 29（上限 64），停止后 0；图标缓存 2（上限 128）。主线程心跳最大间隔 88.3 ms，读取条件和验收阈值沿用上文。数据见 build/validation/interaction-performance.json，不将热缓存启动 235 ms 当作冷启动结论。
